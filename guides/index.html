📘 Hướng Dẫn Sử Dụng Chi Tiết

Phần mềm tự động cào bài viết & bình luận Facebook đa nhóm, hỗ trợ cào nhóm công khai & nhóm kín, tích hợp AI lọc nội dung thông minh (Google AI Studio Gemini / OpenAI) và gửi cảnh báo tức thì về Telegram.

⚡ Direct GraphQL (Siêu nhẹ) 🤖 Google AI Studio (Gemini 2.0 / 2.5 Flash Thinking:0) 📱 Telegram Instant Alerts 💾 SQLite Local Database (~/.facebook-notification/) 🔒 Hỗ trợ Nhóm Kín (Private Groups) 🔄 Cập nhật OTA qua GitHub Releases 🩺 Xuất Chẩn Đoán An Toàn (.diagnose)

📌 1. Tổng Quan Kiến Trúc & Tính Năng

Phần mềm được xây dựng trên nền tảng PyQt6 với kiến trúc đa luồng phi đồng bộ (Multi-threading), chia tách hoàn toàn độc lập giữa:

• Tiến trình cào dữ liệu (ScraperWorker): Tương tác trực tiếp với Facebook GraphQL API để cào bài đăng, ảnh, số reaction, lượt chia sẻ, toàn bộ bình luận và phản hồi lồng nhau.
• Tiến trình phân tích AI (AIWorker / AIDispatcher): Phân tích nội dung theo System Prompt định sẵn, tự động xoay vòng đa model (Multi-Model Fallback) khi gặp lỗi hoặc hạn mức API.
• Tiến trình thông báo (TelegramDispatcher): Gửi cảnh báo tức thì định dạng HTML về kênh cá nhân hoặc nhóm chat Telegram.
• Cơ sở dữ liệu SQLite cục bộ: Tự động lưu trữ tại thư mục người dùng ~/.facebook-notification/facebook_scraper.sqlite, đảm bảo dữ liệu luôn an toàn khi cập nhật ứng dụng.

🕷️
Cào Dữ Liệu Tự Động (Scraper Core)

Sử dụng cơ chế gửi GraphQL Request trực tiếp với Cookie & Token Facebook. Cào toàn bộ nội dung bài đăng, ảnh đính kèm, lượt tương tác và tất cả bình luận/phản hồi phân cấp.

🧠
Trí Tuệ Nhân Tạo AI (Multi-Model Fallback)

Hỗ trợ Google AI Studio (Gemini) và OpenAI / Tương thích (OpenRouter, DeepSeek, Groq...). Tự động vô hiệu hóa suy luận tư duy (thinking_budget: 0) cho Gemini để phản hồi JSON thần tốc.

📱
Cảnh Báo Tức Thì Qua Telegram

Gửi thông báo định dạng HTML đẹp mắt về kênh hoặc nhóm chat Telegram ngay khi phát hiện bài viết hoặc bình luận khớp tiêu chí phân tích của AI.

💾
Lưu Trữ SQLite & Quản Lý Toàn Diện

Toàn bộ bài viết, bình luận, cấu hình và lịch sử phân tích AI được lưu trữ tại SQLite nội bộ. Hỗ trợ lọc, tìm kiếm, xuất Excel/CSV, cập nhật bình luận mới và xóa dữ liệu linh hoạt.

🚀 2. Cài Đặt & Khởi Động

  1. Chạy từ file thực thi (.exe)

    Mở file FacebookNotification.exe (bản cài đặt Setup hoặc bản Portable trong thư mục dist/FacebookNotification/) để mở giao diện chương trình trực tiếp mà không cần cài đặt Python.

  2. Chạy từ mã nguồn Python

    Nếu bạn chạy từ mã nguồn, mở Terminal tại thư mục gốc và chạy lệnh:

    # Cài đặt thư viện phụ thuộc
pip install -r requirements.txt

# Khởi chạy giao diện chính
python run_ui.py
# Hoặc:
python -m src.main
  3. Vị trí lưu trữ dữ liệu người dùng

    Mọi cài đặt và dữ liệu cào được lưu tại thư mục cá nhân của máy tính: ~/.facebook-notification/ (Ví dụ trên Windows: C:\Users\<Tên_User>\.facebook-notification\). Dữ liệu này được giữ nguyên vẹn kể cả khi bạn cập nhật phiên bản mới.

⚙️ 4. Hướng Dẫn Tab 1: Cấu Hình Quét & Quản Lý Nhóm

  1. 🌐 Cách 1: Tự động lấy danh sách Nhóm từ Cookie (Khuyên dùng)

    • Nhấn nút 🌐 Lấy nhóm từ Cookie trên thanh tiêu đề danh sách nhóm.
    • Phần mềm sẽ tự động mở luồng duyệt ngầm an toàn để tải về danh sách toàn bộ các nhóm mà tài khoản Facebook đã tham gia.
    • Tìm kiếm & Lọc tức thì (Filter): Gõ từ khóa tên nhóm, URL, hoặc ID (hỗ trợ tiếng Việt không dấu, ví dụ gõ lap trinh sẽ lọc ngay nhóm Lập Trình Python).
    • Chọn nhóm nhanh: Sử dụng các nút ✅ Chọn tất cả, ⬜ Bỏ chọn, 🔍 Chọn nhóm đang lọc hoặc 🔄 Đảo chọn.
    • Chế độ nhập: Chọn "Thêm vào danh sách hiện tại" (tự động giữ nhóm cũ và loại bỏ link trùng) hoặc "Thay thế toàn bộ" ➔ Nhấn 📥 Nhập nhóm đã chọn.

  2. ➕ Cách 2: Thêm URL Nhóm / Fanpage thủ công

    Bấm nút + Thêm nhóm. Dán link nhóm (ví dụ https://www.facebook.com/groups/123456789/). Nhập tên gợi nhớ nếu muốn. Hoặc bấm ⛶ Phóng to để mở cửa sổ quản lý mở rộng có kèm thanh tìm kiếm/lọc.

  3. 📥 Cách 3: Dán hàng loạt link nhóm (Batch Paste)

    Trong cửa sổ ⛶ Phóng to, bấm 📥 Dán nhiều link ➔ Dán danh sách nhiều URL (mỗi dòng một link) ➔ Bấm Thêm vào danh sách.

  4. Nhập Từ Khóa Lọc (Keywords — Dạng Tag)

    Nhập từ khóa vào ô và nhấn Enter hoặc bấm +. Ví dụ: bán ipad, pass máy, cần nhượng lại. Bấm dấu × trên thẻ tag để xóa từ khóa.

  5. Thiết lập tham số quét

    • Số bài cần cào / nhóm: Số lượng bài viết gần nhất cần lấy (mặc định 5 - 10 bài).
    • Bình luận tối thiểu: Bỏ qua các bài viết có ít hơn số bình luận này (đặt 0 nếu muốn lấy tất cả).
    • 🔄 Quét lặp vô hạn (Infinite Loop): Bật tính năng này để phần mềm tự động quét lại theo chu kỳ định kỳ (ví dụ mỗi 60 giây).

🔒 5. Hướng Dẫn Cào Nhóm Kín & Cấu Hình Cookie

💡 Nguyên lý cào Nhóm Kín (Private Groups): Facebook kiểm tra quyền thành viên trên từng yêu cầu truy vấn GraphQL. Để cào được nhóm kín, tài khoản Facebook dùng lấy Cookie bắt buộc phải là thành viên đã được duyệt vào nhóm đó.
  1. Bước 1: Chuẩn bị tài khoản Facebook

    Đăng nhập tài khoản Facebook (khuyên dùng tài khoản phụ/via/clone) đã tham gia nhóm kín đó trên trình duyệt Chrome/Edge.

  2. Bước 2: Lấy chuỗi Cookie JSON bằng Extension Cookie-Editor

    • Cài đặt tiện ích mở rộng Cookie-Editor (hoặc J2Team Cookies) trên trình duyệt Chrome, Edge, Firefox hoặc Cốc Cốc.
    • Mở tab Facebook đã đăng nhập tài khoản ➔ Bấm vào icon Cookie-Editor trên thanh công cụ.
    • Chọn Export ➔ Chọn Export as JSON (chuỗi JSON Cookie sẽ tự động được sao chép vào bộ nhớ tạm).

  3. Bước 3: Dán vào phần mềm

    Trên Tab 1, bấm nút 🔑 Cấu hình Authentication (Cookie & Token) ➔ Dán chuỗi JSON Cookie vừa sao chép ➔ Tích chọn "Tự động tải danh sách nhóm sau khi lưu" ➔ Bấm Lưu cấu hình.

  4. Bước 4: Bắt đầu cào dữ liệu

    Sau khi chọn xong danh sách nhóm, nhấn 🚀 Bắt đầu cào. Phần mềm sẽ tự động xác thực danh tính thành viên và lấy dữ liệu bài viết, bình luận mượt mà.

⚠️ Lưu ý an toàn tài khoản: • Không sử dụng tài khoản Facebook chính để cào tần suất cao.
• Đặt thời gian nghỉ giữa các đợt quét (Loop interval) từ 60 giây trở lên.
• Kết hợp sử dụng Proxy tại Tab 4 để tránh bị hạn chế IP.

🤖 6. Cấu Hình AI Phân Tích Nội Dung (Tab 4)

Phần mềm hỗ trợ 2 nhà cung cấp AI phổ biến: Google AI Studio (Gemini) và OpenAI / Tương thích.

A. Sử dụng Google AI Studio (Gemini - Khuyên dùng)

Ưu điểm của Google AI Studio: Hạn mức miễn phí (Free Tier) lớn, tốc độ phản hồi cực nhanh. Phần mềm tự động cấu hình thinking_budget: 0 cho Gemini 2.5 Flash / Gemini 2.0 Flash để tắt suy luận tư duy dài dòng, trả về định dạng JSON thuần túy chuẩn xác 100%.
  1. Lấy API Key Google AI Studio miễn phí

    Truy cập aistudio.google.com/app/apikey (hoặc bấm nút màu xanh trên Tab 4) ➔ Đăng nhập tài khoản Google ➔ Bấm Create API key ➔ Copy mã Key (bắt đầu bằng AIzaSy...).

  2. Chọn nhà cung cấp trên phần mềm

    Tại Tab 4, ô Nhà cung cấp AI chọn: ✨ Google AI Studio (Gemini).
    • Ô Base URL sẽ được tự động ẩn (mặc định dùng endpoint chính hãng của Google).
    • Dán API Key vào ô API Key.

  3. Tự động tải danh sách Model qua API Key

    Ngay khi bạn dán API Key (hoặc bấm nút 🔄 Tải Models từ Key), phần mềm sẽ tự động kết nối tới Google và tải toàn bộ các model Gemini khả dụng cho key của bạn vào Bảng Checkbox.

  4. Tích chọn Models cần dùng (Multi-Model Fallback)

    Bạn chỉ cần tích chọn các model mong muốn. Gợi ý:
    • ☑️ gemini-2.5-flash: Model thông minh & chuẩn xác nhất hiện nay.
    • ☑️ gemini-2.0-flash: Tốc độ phản hồi nhanh nhất, chuẩn JSON.
    • ☑️ gemini-1.5-flash: Model dự phòng ổn định, tiết kiệm hạn mức.

B. Sử dụng OpenAI hoặc Proxy LLM tương thích (OpenRouter, DeepSeek, Groq, Ollama...)

  1. Cấu hình Endpoint & API Key

    Chọn nhà cung cấp: 🧠 OpenAI / OpenAI Tương thích.
    • Base URL: Nhập URL endpoint của nhà cung cấp (ví dụ https://api.openai.com/v1, https://openrouter.ai/api/v1, https://api.deepseek.com hoặc proxy riêng). Nếu bỏ trống, phần mềm tự dùng OpenAI chính hãng.
    • API Key: Nhập API Key tương ứng (bắt đầu bằng sk-...).

  2. Quản lý Bảng Model Checkbox & Tự động tải từ API

    • Tải danh sách tự động: Bấm nút 🔄 Tải Models từ API để phần mềm tự động truy vấn danh sách model đang hoạt động từ Base URL / API Key của bạn (tự động lọc bỏ các model embedding, audio, tts, image và sắp xếp theo thứ tự chữ cái A-Z).
    • Thêm model tùy chỉnh: Nhập tên model vào ô "+ Thêm model tùy chỉnh" (ví dụ gpt-4o-mini, meta-llama/llama-3.3-70b-instruct) và bấm + Thêm.
    • Chọn nhanh & Xóa: Sử dụng các nút ✅ Chọn tất cả, ⬜ Bỏ chọn hoặc 🗑 Xóa tất cả để làm sạch danh sách model.

  3. Kiểm tra thực tế (Live Testing) & Hệ thống 4 màu trạng thái

    Bấm nút 🧪 Test AI & Kiểm tra Models để phần mềm gửi request kiểm tra thực tế tới từng model:

    Trạng thái Màu sắc Ý nghĩa & Hành vi
    Chưa kiểm tra 🟡 Vàng / Hổ phách Model mới thêm vào hoặc vừa tải từ API về (chưa xác minh thực tế qua API).
    Đang kiểm tra 🟣 Tím / Indigo Hiển thị ⏳ tên_model (Đang test...) kèm thanh tiến trình cập nhật theo thời gian thực.
    Đã test OK 🟢 Xanh lá cây Hiển thị tên_model ✓. Model phản hồi HTTP 200 và trả về JSON thuần chuẩn (sẵn sàng sử dụng).
    Lỗi API 🔴 Đỏ [Lỗi API] Model gặp lỗi kết nối, quá thời gian chờ, hoặc không trả về JSON thuần (tự động bỏ chọn).
    Thinking / Reasoner 🔴 Đỏ [Thinking] Model tư duy (DeepSeek R1, o1, o3...) tự động bị gạch ngang loại trừ để tránh gây lỗi JSON cho hệ thống.
  4. Cấu hình Timeout AI (giây)

    Tại ô Timeout AI (giây), bạn có thể chỉnh thời gian tối đa chờ phản hồi cho mỗi bài viết (từ 1 đến 9999 giây, mặc định 20 giây). Giúp tránh trường hợp mạng yếu làm treo luồng cào.

🏷️ 7. Mẫu System Prompt Chuẩn Hóa & Hướng Dẫn Tạo Prompt Mới

Phần mềm tích hợp sẵn 4 nút Preset áp dụng ngay các mẫu Prompt chuyên sâu, kèm hướng dẫn Meta-Prompt:

🛒 Mẫu Mua Bán

Chuyên phát hiện bài viết của người cần bán máy/sản phẩm, thanh lý hàng hóa cá nhân. Tự động loại bỏ các tin spam hoặc người hỏi mua.

🏷 Mẫu Tìm Mua

Chuyên phát hiện khách hàng đang có nhu cầu tìm mua sản phẩm, hỏi tìm nơi bán, cần tư vấn dịch vụ.

🏢 Mẫu Phòng Trọ / BĐS

Chuyên tìm kiếm người cho thuê phòng trọ, căn hộ, mặt bằng kinh doanh hoặc người đang đăng tin tìm thuê nhà đất.

💼 Mẫu Việc Làm / Tuyển Dụng

Chuyên phát hiện tin tuyển dụng nhân sự, tìm cộng tác viên, freelance hoặc ứng viên đăng bài tìm việc.

💡 Nút "Hướng dẫn tạo Prompt mới": Mở hộp thoại chứa sẵn khung Meta-Prompt chuẩn cấu trúc JSON. Bạn chỉ cần sao chép khung này gửi cho ChatGPT / Claude / Gemini / DeepSeek để tạo ra System Prompt chuẩn cho bất kỳ ngành nghề nào.
⚡ Tính năng Hot-Reload Prompt & AI: Bạn có thể sửa System Prompt hoặc chuyển đổi Model AI ngay cả khi phần mềm đang quét. Sau khi sửa, chỉ cần bấm 💾 Lưu cấu hình, tiến trình AI Worker đang chạy ngầm sẽ lập tức áp dụng ngay mà không làm gián đoạn việc cào dữ liệu!

📱 8. Cấu Hình Thông Báo Telegram

  1. Tạo Bot và lấy Token

    Mở ứng dụng Telegram ➔ Tìm bot @BotFather (hoặc bấm nút ? cạnh ô Token) ➔ Gửi lệnh /newbot ➔ Đặt tên cho bot ➔ Copy chuỗi HTTP API Token dán vào ô Bot Token.

  2. Lấy Chat ID nhận tin nhắn

    • Nhận qua Chat riêng cá nhân: Tìm bot @userinfobot ➔ Bấm Start ➔ Copy số Id dán vào ô Chat ID.
    • Nhận qua Nhóm Telegram: Thêm bot vừa tạo vào nhóm ➔ Thăng quyền Admin cho bot ➔ Lấy ID nhóm (thường có dấu - ở đầu, ví dụ -1001234567890).

  3. Kiểm tra kết nối

    Bấm nút 🔔 Gửi tin nhắn kiểm tra kết nối Telegram. Nếu nhận được tin nhắn test trên Telegram là cấu hình hoàn toàn chính xác.

🌐 9. Cấu Hình Proxy Chống Chặn IP

Tại Tab 4, ô Proxy (Tĩnh hoặc Xoay) cho phép nhập proxy để bảo vệ địa chỉ IP máy chủ khi quét liên tục.

Định dạng được hỗ trợ:

# Proxy không có mật khẩu (IP:Port)
103.150.12.34:8080

# Proxy có tài khoản & mật khẩu (User:Pass@IP:Port hoặc IP:Port:User:Pass)
admin:123456@103.150.12.34:8080
103.150.12.34:8080:admin:123456

# Proxy có tiền tố giao thức
http://admin:123456@103.150.12.34:8080

❓ 15. Câu Hỏi Thường Gặp (FAQ)

1. Cookie Facebook sống được bao lâu? Khi nào cần lấy lại?

Cookie thường có hiệu lực từ vài ngày đến vài tuần. Nếu bạn đăng xuất tài khoản trên trình duyệt hoặc đổi mật khẩu, Cookie sẽ hết hạn. Khi thấy thông báo lỗi xác thực hoặc không lấy được bài nhóm kín, hãy cập nhật lại Cookie mới tại Tab 1.

2. Tôi có thể vừa cào vừa sửa System Prompt hoặc đổi Model AI được không?

Hoàn toàn được! Phần mềm hỗ trợ tính năng Hot-Reload. Bạn chỉ cần sửa Prompt hoặc chọn Model tại Tab 4 rồi bấm Lưu cấu hình, tiến trình AI đang chạy sẽ ngay lập tức áp dụng cài đặt mới mà không cần dừng quét.

3. File cơ sở dữ liệu SQLite lưu ở đâu? Có bị mất khi update phần mềm không?

File cơ sở dữ liệu nằm tại ~/.facebook-notification/facebook_scraper.sqlite (thư mục User). Khi bạn cài đặt hoặc cập nhật phiên bản mới của phần mềm, toàn bộ dữ liệu, cấu hình và bài viết đã cào vẫn được giữ nguyên vẹn 100%.
