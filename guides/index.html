📘 Hướng Dẫn Sử Dụng Chi Tiết

Phần mềm tự động cào bài viết & bình luận Facebook đa nhóm, hỗ trợ cào nhóm công khai & nhóm kín, tích hợp AI lọc nội dung thông minh (Google AI Studio Gemini / OpenAI) và gửi cảnh báo tự động về Telegram.

⚡ Không dùng Chrome UI (Siêu nhẹ) 🤖 Google AI Studio (Gemini 2.0 / 2.5) 📱 Telegram Instant Alerts 💾 SQLite Local Database 🔒 Hỗ trợ Nhóm Kín (Private Groups)

📌 1. Tổng Quan Kiến Trúc & Tính Năng

Phần mềm được thiết kế theo kiến trúc phi đồng bộ (Multi-threading), chia tách độc lập giữa tiến trình cào dữ liệu và tiến trình AI phân tích. Điều này giúp phần mềm hoạt động mượt mà, không bị nghẽn (freeze giao diện) ngay cả khi cào hàng chục nhóm Facebook liên tục.

🕷️
Cào Dữ Liệu Tự Động (Scraper Core)

Sử dụng cơ chế gửi GraphQL Request trực tiếp với Cookie & Token Facebook. Cào toàn bộ nội dung bài đăng, ảnh, số lượt thích/chia sẻ, toàn bộ bình luận và phản hồi bình luận lồng nhau.

🧠
Trí Tuệ Nhân Tạo AI (Multi-Model Fallback)

Hỗ trợ Google AI Studio (Gemini) và OpenAI. Tự động chuyển đổi sang model dự phòng nếu model chính bị lỗi hoặc quá hạn mức (Rate limit). Tự động tắt suy luận tư duy để trả về JSON thuần siêu tốc.

📱
Cảnh Báo Tức Thì Qua Telegram

Gửi thông báo định dạng HTML đẹp mắt về kênh hoặc nhóm chat Telegram ngay khi phát hiện bài viết hoặc bình luận khớp tiêu chí phân tích của AI.

💾
Lưu Trữ SQLite & Quản Lý Toàn Diện

Toàn bộ bài viết, bình luận, cấu hình và lịch sử phân tích AI được lưu trữ tại file SQLite nội bộ. Hỗ trợ lọc, tìm kiếm, xuất file Excel/CSV, cập nhật bình luận mới và xóa dữ liệu linh hoạt.

🚀 2. Cài Đặt & Khởi Động

  1. Chạy từ file thực thi (.exe)

    Vào thư mục dist/FacebookNotification/, nhấp đúp vào file FacebookNotification.exe để mở giao diện chương trình trực tiếp mà không cần cài Python.

  2. Chạy từ mã nguồn Python

    Nếu bạn là lập trình viên, mở Terminal tại thư mục gốc và chạy lệnh:

    # Cài đặt thư viện phụ thuộc (nếu chưa cài)
pip install -r requirements.txt

# Khởi chạy giao diện chính
python -m src.main

⚙️ 4. Hướng Dẫn Tab 1: Cấu Hình Quét & Quản Lý Nhóm

  1. 🌐 Cách 1: Tự động lấy danh sách Nhóm từ Cookie (Khuyên dùng)

    • Nhấn nút 🌐 Lấy nhóm từ Cookie trên thanh tiêu đề danh sách nhóm (hoặc cấu hình Cookie và chọn "Tự động tải danh sách nhóm").
    • Phần mềm sẽ tự động kết nối Facebook tải về danh sách toàn bộ các nhóm mà tài khoản đã tham gia.
    • Tìm kiếm & Lọc tức thì (Filter): Gõ từ khóa tên nhóm, URL, hoặc ID (hỗ trợ tiếng Việt không dấu, ví dụ gõ lap trinh sẽ lọc ngay nhóm Lập Trình Python).
    • Chọn nhóm nhanh: Sử dụng các nút ✅ Chọn tất cả, ⬜ Bỏ chọn, 🔍 Chọn nhóm đang lọc hoặc 🔄 Đảo chọn.
    • Chế độ nhập: Chọn "Thêm vào danh sách hiện tại" (tự động giữ nhóm cũ và loại bỏ link trùng) hoặc "Thay thế toàn bộ" ➔ Nhấn 📥 Nhập nhóm đã chọn.

  2. ➕ Cách 2: Thêm URL Nhóm / Fanpage thủ công

    Bấm nút + Thêm nhóm. Dán link nhóm (ví dụ https://www.facebook.com/groups/123456789/). Nhập tên gợi nhớ nếu muốn. Hoặc bấm ⛶ Phóng to để mở cửa sổ quản lý mở rộng có kèm thanh tìm kiếm/lọc.

  3. 📥 Cách 3: Dán hàng loạt link nhóm (Batch Paste)

    Trong cửa sổ ⛶ Phóng to, bấm 📥 Dán nhiều link ➔ Dán danh sách nhiều URL (mỗi dòng một link) ➔ Bấm Thêm vào danh sách.

  4. Nhập Từ Khóa Lọc (Keywords)

    Nhập từ khóa vào ô và nhấn Enter hoặc bấm +. Ví dụ: bán ipad, pass máy, cần nhượng lại. Bấm dấu × trên thẻ tag để xóa từ khóa.

  5. Thiết lập tham số quét

    • Số bài cần cào / nhóm: Số lượng bài viết gần nhất cần lấy (mặc định 5 - 10 bài).
    • Bình luận tối thiểu: Bỏ qua các bài viết có ít hơn số bình luận này (đặt 0 nếu muốn lấy tất cả).
    • 🔄 Quét lặp vô tận (Infinite Loop): Bật tính năng này để phần mềm tự động quét lại theo chu kỳ định kỳ (ví dụ mỗi 60 giây).

🔒 5. Hướng Dẫn Cào Nhóm Kín & Cấu Hình Cookie

💡 Nguyên lý cào Nhóm Kín (Private Groups): Facebook kiểm tra quyền thành viên trên từng yêu cầu truy vấn GraphQL. Để cào được nhóm kín, tài khoản Facebook dùng lấy Cookie bắt buộc phải là thành viên đã được duyệt vào nhóm đó.
  1. Bước 1: Chuẩn bị tài khoản Facebook

    Đăng nhập tài khoản Facebook (khuyên dùng nick phụ/via/clone) đã tham gia nhóm kín đó trên trình duyệt Chrome/Edge.

  2. Bước 2: Lấy chuỗi Cookie JSON bằng Extension Cookie-Editor

    • Cài đặt tiện ích mở rộng Cookie-Editor (hoặc J2Team Cookies) trên trình duyệt Chrome, Edge, Firefox hoặc Cốc Cốc.
    • Mở tab Facebook đã đăng nhập tài khoản ➔ Bấm vào icon Cookie-Editor trên thanh công cụ.
    • Chọn Export ➔ Chọn Export as JSON (chuỗi JSON Cookie sẽ tự động được sao chép vào bộ nhớ tạm).

  3. Bước 3: Dán vào phần mềm

    Trên Tab 1, bấm nút 🔑 Cấu hình Authentication (Cookie JSON Facebook) ➔ Dán chuỗi JSON Cookie vừa sao chép ➔ Tích chọn "Tự động tải danh sách nhóm sau khi lưu" ➔ Bấm Lưu cấu hình.

  4. Bước 4: Bắt đầu cào dữ liệu

    Sau khi chọn xong danh sách nhóm, nhấn 🚀 Bắt đầu cào. Phần mềm sẽ tự động xác thực danh tính thành viên và lấy dữ liệu bài viết, bình luận mượt mà.

⚠️ Lưu ý an toàn tài khoản: • Không sử dụng tài khoản Facebook chính để cào tần suất cao.
• Đặt thời gian nghỉ giữa các đợt quét (Loop interval) từ 60 giây trở lên.
• Kết hợp sử dụng Proxy tại Tab 4 để tránh bị hạn chế IP.

🤖 6. Cấu Hình AI Phân Tích Nội Dung (Tab 4)

Phần mềm hỗ trợ 2 nhà cung cấp AI phổ biến: Google AI Studio (Gemini) và OpenAI / Tương thích.

A. Sử dụng Google AI Studio (Gemini - Khuyên dùng)

Ưu điểm của Google AI Studio: Cung cấp hạn mức miễn phí rất lớn (Free Tier), tốc độ phản hồi cực nhanh, hỗ trợ các model tiên tiến như Gemini 2.0 Flash, Gemini 2.5 Flash.
  1. Lấy API Key Google AI Studio miễn phí

    Truy cập aistudio.google.com/app/apikey ➔ Đăng nhập tài khoản Google ➔ Bấm Create API key ➔ Copy mã Key (bắt đầu bằng AIzaSy...).

  2. Chọn nhà cung cấp trên phần mềm

    Tại Tab 4, ô Nhà cung cấp AI chọn: ✨ Google AI Studio (Gemini).
    • Ô Base URL sẽ được tự động ẩn (mặc định dùng endpoint chính hãng của Google).
    • Dán API Key vào ô API Key.

  3. Tự động tải danh sách Model qua API Key

    Ngay khi bạn dán API Key (hoặc bấm nút 🔄 Tải Models từ Key), phần mềm sẽ tự động kết nối tới Google và tải toàn bộ các model Gemini khả dụng cho key của bạn vào Bảng Checkbox.

  4. Tích chọn Models cần dùng

    Bạn chỉ cần tích chọn các model mong muốn. Gợi ý:
    • ☑️ gemini-2.0-flash: Tốc độ phản hồi nhanh nhất, chuẩn JSON.
    • ☑️ gemini-2.5-flash: Model thông minh mới nhất.
    • ☑️ gemini-1.5-flash: Ổn định, tiết kiệm hạn mức.

B. Sử dụng OpenAI hoặc Proxy LLM tương thích (OpenRouter, DeepSeek, Groq, Ollama...)

  1. Cấu hình Endpoint & API Key

    Chọn nhà cung cấp: 🧠 OpenAI / OpenAI Tương thích.
    • Base URL: Nhập URL endpoint của nhà cung cấp (ví dụ https://api.openai.com/v1, https://openrouter.ai/api/v1, https://api.deepseek.com hoặc proxy riêng). Nếu bỏ trống, phần mềm tự dùng OpenAI chính hãng.
    • API Key: Nhập API Key tương ứng (bắt đầu bằng sk-...).

  2. Quản lý Bảng Model Checkbox & Tự động tải từ API

    • Tải danh sách tự động: Bấm nút 🔄 Tải Models từ API để phần mềm tự động truy vấn danh sách model đang hoạt động từ Base URL / API Key của bạn (tự động lọc bỏ các model embedding, audio, tts, image và sắp xếp theo thứ tự chữ cái A-Z).
    • Thêm model tùy chỉnh: Nhập tên model vào ô "+ Thêm model tùy chỉnh" (ví dụ gpt-4o-mini, meta-llama/llama-3.3-70b-instruct) và bấm + Thêm.
    • Chọn nhanh & Xóa: Sử dụng các nút ✅ Chọn tất cả, ⬜ Bỏ chọn hoặc 🗑 Xóa tất cả để làm sạch danh sách model.

  3. Kiểm tra thực tế (Live Testing) & Hệ thống trạng thái màu sắc

    Bấm nút 🧪 Test AI & Kiểm tra Models để phần mềm gửi request thực tế tới từng model:

    Trạng thái Màu sắc Ý nghĩa & Hành vi
    Chưa kiểm tra 🟡 Vàng / Hổ phách Model mới thêm vào hoặc vừa tải từ API về (chưa xác minh thực tế qua API).
    Đang kiểm tra 🟣 Tím / Indigo Hiển thị ⏳ tên_model (Đang test...) kèm thanh tiến trình cập nhật theo thời gian thực.
    Đã test OK 🟢 Xanh lá cây Hiển thị tên_model ✓. Model phản hồi HTTP 200 và trả về JSON thuần chuẩn (sẵn sàng sử dụng).
    Lỗi API 🔴 Đỏ [Lỗi API] Model gặp lỗi kết nối, quá thời gian chờ, hoặc không trả về JSON thuần (tự động bỏ chọn).
    Thinking / Reasoner 🔴 Đỏ [Thinking] Model tư duy (DeepSeek R1, o1, o3...) tự động bị gạch ngang loại trừ để tránh gây lỗi JSON cho hệ thống.

    • Chạy nền không đơ giao diện (Non-blocking): Toàn bộ quá trình kiểm tra chạy trên luồng nền riêng biệt.
    • Nút Dừng tức thì: Khi đang test, nút tự chuyển sang ⏹ Dừng test (i/N), bạn có thể bấm để dừng kiểm tra bất kỳ lúc nào.
    • Hỗ trợ Server-Sent Events (SSE): Tương thích hoàn hảo với cả các máy chủ proxy trả về stream data: {"id":...}.

C. Cấu hình System Prompt & Mẫu có sẵn

Phần mềm tích hợp sẵn các mẫu Prompt chuẩn hóa chuyên sâu:

• 🏷 Mẫu Tìm Bán: Chuyên phát hiện bài viết của người cần bán máy/sản phẩm, loại bỏ các tin spam hoặc người hỏi mua.
• 🏷 Mẫu Tìm Mua: Chuyên phát hiện khách hàng đang có nhu cầu tìm mua sản phẩm.
• 💡 Hướng dẫn tạo Prompt mới: Mở hộp thoại chứa mẫu Meta-Prompt để gửi cho ChatGPT/Claude/Gemini tự thiết kế Prompt mới theo bất kỳ ngành nghề nào (Bất động sản, Tuyển dụng, Ô tô, Gia sư...).

📱 7. Cấu Hình Thông Báo Telegram

  1. Tạo Bot và lấy Token

    Mở ứng dụng Telegram ➔ Tìm kiếm bot @BotFather ➔ Gửi lệnh /newbot ➔ Đặt tên cho bot ➔ Copy chuỗi HTTP API Token dán vào ô Bot Token.

  2. Lấy Chat ID nhận tin nhắn

    • Nhận qua Chat riêng: Tìm bot @userinfobot ➔ Bấm Start ➔ Copy số Id dán vào ô Chat ID.
    • Nhận qua Nhóm Telegram: Thêm bot vừa tạo vào nhóm ➔ Thăng quyền Admin cho bot ➔ Lấy ID nhóm (thường có dấu - ở đầu, ví dụ -100123456789).

  3. Kiểm tra kết nối

    Bấm nút 🔔 Gửi thử nghiệm kết nối. Nếu nhận được tin nhắn test trên Telegram là cấu hình thành công.

🌐 8. Cấu Hình Proxy Chống Chặn IP

Tại Tab 4, ô Proxy (Tĩnh hoặc Xoay) cho phép nhập proxy để bảo vệ địa chỉ IP máy chủ khi quét liên tục.

Định dạng được hỗ trợ:

# Proxy không có mật khẩu
123.45.67.89:8080

# Proxy có tài khoản & mật khẩu
123.45.67.89:8080:username:password

# Proxy có tiền tố giao thức
http://username:password@123.45.67.89:8080
socks5://username:password@123.45.67.89:1080

💬 10. Tính Năng Cập Nhật Bình Luận Mới

Tại sao cần cập nhật bình luận? Nhiều khách hàng hoặc người bán không đăng thông tin ở bài viết gốc mà bình luận bên dưới bài viết sau đó vài giờ. Tính năng này giúp bạn quét lại toàn bộ bình luận mới nhất mà không cần cào lại từ đầu.
  1. Cách 1: Cập nhật bình luận các bài đã chọn

    Tại Tab 2, tích chọn các bài viết bạn muốn theo dõi ➔ Bấm nút 💬 Cập nhật bình luận đã chọn.

  2. Cách 2: Cập nhật bình luận 24h vừa qua

    Bấm nút 🕒 Cập nhật bình luận 24h vừa qua. Hệ thống sẽ tự động lọc tất cả bài viết có thời gian đăng trong vòng 24 giờ qua và tiến hành cào lại bình luận.

  3. Tự động đẩy vào luồng AI & Telegram

    Toàn bộ bình luận mới cập nhật sẽ được chuyển ngay vào AI Analysis Queue. Nếu AI phát hiện có bình luận khớp tiêu chí, thông báo Telegram sẽ được gửi ngay lập tức.

❓ 12. Câu Hỏi Thường Gặp (FAQ)

1. Cookie Facebook sống được bao lâu? Khi nào cần lấy lại?

Cookie thường có hiệu lực từ vài ngày đến vài tuần. Nếu bạn đăng xuất tài khoản trên trình duyệt hoặc đổi mật khẩu, Cookie sẽ hết hạn. Khi thấy thông báo lỗi xác thực hoặc không lấy được bài nhóm kín, hãy cập nhật lại Cookie mới.

2. Tôi có thể vừa cào vừa sửa System Prompt hoặc đổi Model AI được không?

Hoàn toàn được! Phần mềm hỗ trợ tính năng Hot-Reload. Bạn chỉ cần sửa Prompt hoặc chọn Model tại Tab 4 rồi bấm Lưu cấu hình, tiến trình AI đang chạy sẽ ngay lập tức áp dụng cài đặt mới mà không cần dừng quét.

3. File cơ sở dữ liệu SQLite lưu ở đâu? Có mang sang máy khác được không?

File cơ sở dữ liệu nằm tại data/facebook_scraper.db. Bạn có thể sao chép thư mục data/ sang máy tính khác để giữ nguyên toàn bộ bài viết và lịch sử đã cào.

🛠️ 13. Xử Lý Sự Cố (Troubleshooting)

Hiện tượng / Lỗi Nguyên nhân Cách khắc phục
Không lấy được bài nhóm kín (0 bài) Tài khoản chưa vào nhóm kín hoặc Cookie bị hết hạn. Kiểm tra xem nick Facebook đã được duyệt vào nhóm chưa và cập nhật lại Cookie & fb_dtsg tại Tab 1.
AI báo lỗi HTTP 429 (Rate Limit) Hết hạn mức gọi API trong phút của Model. Tích chọn thêm 2-3 model dự phòng (như Gemini 2.0 Flash, Gemini 1.5 Flash) để phần mềm tự động chuyển đổi khi gặp lỗi.
Telegram không nhận được tin nhắn Sai Token hoặc chưa bấm /start bot. Mở chat với bot trên Telegram, bấm nút Start và kiểm tra lại Chat ID tại Tab 4.
