📘 User Guide & Documentation

High-performance desktop application for extracting Facebook posts & comments across public and private groups, intelligent AI filtering (Google Gemini & OpenAI / OpenRouter / DeepSeek), and real-time Telegram alerts.

⚡ Direct GraphQL (Lightweight) 🤖 Google AI Studio (Gemini 2.5 Flash Thinking:0) 📱 Telegram Instant Alerts 💾 Local SQLite (~/.facebook-notification/) 🔒 Private Groups Support 🔄 OTA Updates via GitHub Releases 🌐 Instant Multilingual (EN / VI)

📌 1. Architecture & Key Features

Built with PyQt6 on an asynchronous multi-threaded architecture with fully decoupled pipelines:

• Scraper Worker Pipeline: Communicates directly with Facebook GraphQL API via HTTP requests to scrape posts, media attachments, reactions, shares, and hierarchical comments & replies.
• AI Analyzer Worker: Processes posts against customized System Prompts, supporting multi-model rotation & fallback on rate limits.
• Telegram Dispatcher: Dispatches instant formatted HTML alerts to your Telegram chat or channels as soon as matching leads are identified.
• Optimized Local SQLite: Stored in user home directory at ~/.facebook-notification/facebook_scraper.sqlite with PRAGMA WAL write-ahead logging.

🕷️
Parallel Group Scraping (1-10 Threads)

Scrapes multiple independent Facebook groups concurrently without opening browser windows. Up to 10 parallel worker threads.

🧠
Dual AI Provider & Multi-Model Rotation

Native Google Gemini API and all OpenAI-compatible endpoints (DeepSeek, OpenRouter, Groq, Ollama) with automatic fallback.

🔍
Deep Boolean Logic Filter

Full support for AND, OR, NOT, and nested parentheses with live natural language explainer.

🛡️
Multi-Level Deduplication Engine

Prevents redundant AI token consumption by checking post_id and comment_id before invoking AI APIs.

🖥️ 3. UI Layout Overview (4 Tabs)

Tab Name Core Functionality
Tab 1 Scrape Data Manage target groups, adjust scraping parameters (Posts/group, Min comments, Threads, Cutoff time), configure keyword filter, start/stop scraper.
Tab 2 Scraped Data Search and manage all scraped posts, view full post details & media, update comments, export data.
Tab 3 AI History Review posts evaluated with should_notify = True, inspect AI reasoning, resend Telegram alerts.
Tab 4 Settings Configure Telegram Bot Token & Chat ID, Google Gemini & OpenAI API Keys, System Prompt, Proxies, and OTA Updates.

⚙️ 4. Tab 1: Scraping Parameters & Groups

Scraping Parameters Toolbar:
Parameter Description & Recommended Setting
Posts/group Maximum posts to fetch per group per scraping cycle (Default: 10).
Min comments Comment scraping rule:
• 0 (Default): Skip comments (posts only, fastest speed).
• -1: Scrape all comments and nested replies.
• > 0 (e.g. 5, 20): Scrape up to N comments/post without skipping posts.
Threads Concurrent group scraping workers (1 - 10). Recommended: 3-5 threads.
Cutoff Time Filter posts from 1, 2, 3, 7 days ago or custom datetime. Stops pagination once older posts are encountered.
Infinite Loop Automatically restart scraping cycles after the specified sleep interval.
Sleep Interval Rest duration between automated cycles (Default: 60 seconds).

🔒 5. Private Groups & Cookie Setup

Export your Facebook session cookie in standardized JSON format using Cookie-Editor:

  • Install Extension & Login

    Log in to Facebook on Chrome/Edge and open the Cookie-Editor browser extension.

  • Export as JSON

    Click Export ➔ Export as JSON (copied to clipboard).

  • Paste & Save in App

    Click 🔑 Facebook Cookie in the top header, paste the JSON, click ⚡ Parse, then 💾 Save Settings.

⚠️
To Remove Cookies: Empty the Cookie dialog input box and click *Save Settings* to completely reset credentials.

🔍 6. Boolean Keyword Filter & Logic Explainer

Click ⚙️ Filter Config in Tab 1 to build advanced filters:

🧱
Dual-Mode Editor

• Visual Rule Builder: Build conditions visually with group cards, dropdown operators (AND, OR, NOT), and connector logic.
• Raw Expression Mode: Directly type standard Boolean queries such as ("apartment" OR "room") AND ("downtown" OR "suburb") AND NOT "agent".
• Real-Time Explainer: Automatically translates your syntax into clear natural language sentences.

🤖 7. AI Configuration (Gemini & OpenAI)

Navigate to Tab 4: Settings ➔ AI Configuration:

🌟
Google AI Studio (Gemini)

Free API key from aistudio.google.com. Check models to rotate: gemini-2.5-flash, gemini-1.5-flash, gemini-2.5-pro.

⚡
OpenAI & Compatible Endpoints

Configure Base URL and API Key for DeepSeek, OpenRouter, Groq, Together AI, or local LLMs (Ollama, LM Studio).

🏷️ 8. Standard System Prompts

Choose ready-made presets in Tab 4 or provide your own custom Prompt with strictly enforced JSON schema:

{
  "should_notify": true,
  "confidence_score": 0.95,
  "matched_keyword_or_demand": "Looking to buy Sony A7IV camera",
  "estimated_price": "25,000,000 VND",
  "quote_evidence": "Need to buy Sony A74 body with low shutter count",
  "short_assessment": "Buyer actively looking for camera gear."
}

📱 9. Real-Time Telegram Alerts

  • Create Bot with @BotFather

    Message @BotFather on Telegram, send /newbot, and copy your Bot Token.

  • Obtain Chat ID

    Message @userinfobot for your personal ID, or add your bot to a group and message @RawDataBot for group Chat ID.

  • Start Conversation (Mandatory)

    Open a direct chat with your bot and click /start so Telegram allows it to deliver messages.

🌐 10. Proxy Configuration

Enter HTTP/HTTPS/SOCKS5 proxies in format http://user:pass@ip:port to bypass regional blocks or network restrictions.

🩺 11. Technical Diagnostics

Click 🩺 Export Diagnostics in Tab 4 to generate an anonymized report diagnostics_report.json (guaranteed free of private Cookies and API keys).

🔄 12. Over-The-Air (OTA) Updates

Click 🔍 Check for Updates to check GitHub Releases and download updates directly within the app.

📊 13. Managing Scraped Posts (Tab 2)

💬 14. Comment Updates for Active Posts

Click 🔄 Update Selected Comments or ⏱️ Update Last 24h Comments to fetch new replies on hot posts without rescraping the entire group.

🧠 15. AI Lead Analysis History (Tab 3)

Review high-intent leads, inspect price quotes and reasoning snippets, and resend notifications with 🔔 Resend Telegram.

❓ 16. Frequently Asked Questions (FAQ)

Question Solution
Cannot scrape private groups? Make sure you have joined the group on Facebook and updated your valid Session Cookie JSON in the Cookie dialog.
AI returns Rate Limit 429? Check multiple AI models in Tab 4. The application automatically rotates to backup models when one is rate-limited.
Telegram test message fails? Ensure you have clicked /start in a private chat with your bot first.
